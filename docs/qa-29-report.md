## Что сделано в Wokwi повторно

Неизменённый скетч скомпилирован и запущен в новом контрольном проекте Mega + MAX7219 8×8. Использованы прежние соединения по коду; в diagram.json изменено только положение изображения джойстика для удобства просмотра. Это контрольная схема аналитика, а не подтверждение согласования схемы #12 командой.

Тестовые ключи: P=0,1,9,10; Q=0,8,9,17, длина 4. Ввод через Serial: первая P — edsde; первая Q — esdse; после ошибки Q — sdse, P — dsde. Между попытками проверено состояние программы.

| Проверки | Наблюдение в Wokwi | Результат |
|---|---|---|
| TC-01/03/25: старт, первая запись | Программа запустилась, P записан в EEPROM, доступен новый ввод | Подтверждено в пределах сеанса |
| TC-09/10: две ошибки подряд | Q дал Wrong attempt 1, затем Wrong attempt 2; открытия нет | Пройдено |
| TC-15: правильный ключ после двух ошибок | P принят, SG90 открылся до 90°, удержание, закрытие; последующая Q дала Wrong attempt 1 | Пройдено через Serial |
| TC-24: повторный цикл | После закрытия введён Q, затем P; верный ключ открыл замок повторно, затем серво закрылось без перезапуска | Пройдено через Serial |

Журнал повторного сеанса: [wokwi-29.log](wokwi-29.log). Снимок: [wokwi-29.jpg](wokwi-29.jpg). Проверки Serial не подтверждают те же действия виртуальным стиком. Прямое управление стиком пробовалось, но его отклонения в журнале надёжно не зафиксированы; этим попыткам статус «пройдено» не присваивается.

## Дополнительные проверки логики на ПК

Собрана C++17 программа с исходным скетчем и заглушками millis, EEPROM и периферии. Выполнено 9 проверок: **6 прошли, 3 выявили расхождения**. Это отдельные проверки логики, не Wokwi и не физический стенд.

| Имя проверки | Что проверяли | Результат |
|---|---|---|
| neutral | Внутренняя точка, нейтраль 5 с: лишних шагов нет | Пройдено |
| four_directions | Из точки 9: вверх 1, вниз 17, влево 8, вправо 10 | Пройдено |
| all_path_boundaries | Четыре выхода за границы через INPUT_PATH: длина и счётчик неизменны | Пройдено |
| button_bounce | Чередование контакта 5 мс, затем удержание и второе нажатие | Пройдено: нет раннего события, затем по одному событию на нажатие |
| success_resets_errors | Q, Q, P, закрытие, Q | Пройдено: последняя ошибка считается первой |
| repeat_cycle | P, закрытие, Q, P, закрытие | Пройдено |
| block_duration | Интервал BLOCKED | Не пройдено: 10000 вместо 30000 мс, #17 |
| unauth_reset | r, запись нового Q, открытие Q без старого P | Не пройдено, #18 |
| choose_joystick | Выбор первой точки и SEL без Serial | Не пройдено для автономного управления: currentLED=0, CHOOSE_START; [#19](https://github.com/Mys2018/Arduino-based-pattern-lock/issues/19) |

Исходники и логи: [qa-29.zip](qa-29.zip). Машинный итог: [qa-results-29.json](qa-results-29.json). У кнопки проверялась программная фильтрация, а не реальные электрические контакты. Нейтраль со смещённым центром и автокалибровка не проверены.
